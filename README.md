Currently not public, internal cleanup and polish is being made for a public release.

Azalea is a terraria client that focuses on adding new features that improve the gameplay experience.

Azalea is a fork of [Unified](https://github.com/gold-meridian/terraria-unified).

Azalea is not a modloader, for that please use [tModLoader](https://github.com/tModLoader/tModLoader).

Azalea is not a cheat client, it's main focus is adding new features and optimizations, not cheats.

# Features

Some small optimizations

Some tModLoader mods ported. (open source ones only!)

Several chat related tweaks.

More server commands than vanilla.

Discord Rich Presence.

and way more!
